# profitOS · anteprima funnel

Anteprima statica del funnel profitOS. Pagina di vendita, opt-in e cruscotto.

- `index.html` — la VSL
- `optin.html` — opt-in con modulo
- `cruscotto.html` — cruscotto numeri del funnel

Le pagine hanno `noindex`: servono a far vedere il lavoro, non a essere indicizzate.
La destinazione definitiva della VSL è GoHighLevel.
